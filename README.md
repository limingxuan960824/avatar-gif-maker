# 头像 GIF 工坊

一个完全在浏览器本地运行的头像聊天气泡 GIF 生成器。

## 功能

- PNG、JPG、WEBP 头像导入与圆形裁切
- 头像缩放和位置调整
- 滑动、弹跳、摇头、呼吸、漂浮五种动画
- 深灰、雾白、樱红、薄荷四种气泡样式
- 透明背景 GIF 导出
- 手机和电脑自适应界面

头像不会上传到服务器。GIF 编码也在浏览器中完成。

## 本地使用

直接打开 `index.html`，或在 Windows 中双击 `启动工具.cmd`。

## 技术说明

项目使用原生 HTML、CSS、Canvas 与 JavaScript，不依赖后端服务或第三方 CDN，可直接部署到 GitHub Pages。
